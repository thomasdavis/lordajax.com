## Alpha

A programming language and compiler, written in Haskell, for training models. You write the model, how it learns, the training loop and the GPU it runs on as one program. The compiler type-checks all of it, then writes every byte of the executable itself: host code, GPU machine code, the ELF around them. No CUDA, no PyTorch, no vendor runtime. It talks to the driver directly. It trains GPT-2 on my RTX 3070, and AI agents write most of the compiler under rules I set. The code is private for now; I write about it in the [devlog](/devlog/).

## cdnjs

I co-founded [cdnjs](https://cdnjs.com) with Ryan Kirkman in 2011, a free CDN for the JavaScript libraries Google's CDN didn't carry. Cloudflare came on board a few months later and runs it today.

- 3.3 trillion requests in the last year (Oct 2025 – Sep 2026), about 9 billion a day
- 78 petabytes of JavaScript and CSS served in that same year
- on about 11% of all websites, and on nearly half of the sites that use a JavaScript CDN
- 4,600+ libraries, 1,700+ contributors, 10,700 GitHub stars

## JSON Resume

I co-founded [JSON Resume](https://jsonresume.org) with Roland Sharp in 2014. It's an open standard for writing your resume as JSON.

- 7,000+ GitHub stars across the repos, tens of thousands of users
- a registry that renders any resume in 52 themes ([here's mine](https://registry.jsonresume.org/thomasdavis))
- job matching that scores your resume against Hacker News hiring posts
